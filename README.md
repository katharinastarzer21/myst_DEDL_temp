# DEDL Notebook Gallery
## Setup and Configuration

The DEDL Gallery Website provides a structured overview of all available notebooks in the Destination Earth Data Lake, grouped into three core services: **HOOK**, **STACK**, and **HDA**. This document explains how the site is set up, how it works, and how to modify or extend its configuration.

Below is an overview of the repository structure, followed by a step-by-step guide on how to contribute to the gallery.

# Repository Structure

## 1. `_static/`
The `custom.css` file defines the visual appearance of the site (colors, fonts, spacing, header sizes). Any visual adjustments can be made directly in this file.


## 2. `img/`
Contains all images used by the notebooks or the website. When adding a notebook, include your thumbnail here and reference it in the first Markdown cell.

See the **Contributing** section for details.


## 3. `scripts/`
Contains Python scripts that automate gallery generation and site configuration.

### `clone_sync_repos.py`
Clones the DEDL Lab repo (`staging` branch), copies the folders `HDA`, `HOOK`, and `STACK` into `production/`, and processes external repositories listed in `cookbooks.json`.

### `generate_gallery_md.py`
Extracts metadata from the first Markdown cell of each notebook and creates gallery pages in `galleries/`.

### `generate_keywords.py`
Creates tag-based gallery pages by scanning and grouping notebooks by their tags. Output is stored in `galleries_by_tag/`.

### `parse_issue.py`
Parses issue submissions to generate or update `cookbook.json` entries for newly submitted repositories.

### `indexbutton.py`
Updates all gallery pages by regenerating tag filter buttons placed below the marker `### Filter Notebooks by Tags`.

### `build_myst_yml.py`
Generates the `myst.yml` configuration file and defines global site settings, theme elements, and navigation.

> Structural changes should be implemented inside this script rather than editing `myst.yml` directly.


## 4. `.github/`
Contains issue templates and GitHub Actions workflows.

### `ISSUE_TEMPLATE/`
Defines the issue form (`submit_repo.yml`) for submitting new external cookbooks.

### `workflows/`
Two automation workflows are defined:

#### `build_myst_page.yml`
Triggered on every push to `main`.
Executes all gallery-generation scripts and updates:

- `production/`
- `galleries/`
- `galleries_by_tag/`
- `img/`
- `myst.yml`
- `index.md`

#### `integrate_cookbook.yml`
Triggered when an issue is closed (currently permitted only for selected users). Parses the submission, updates `cookbook.json`, rebuilds gallery pages, and regenerates the site configuration.


## 5. Additional Files

### `myst.yml`
Defines the MyST site configuration. Automatically generated by `build_myst_yml.py`.

### `footer.md`
Footer content included on every gallery page.

### `contribute.md`
Contains contribution guidelines. Should be kept in sync with the instructions below.

### `cookbooks.json`
Stores metadata for externally contributed repositories. Automatically maintained by workflows.

# How to Contribute

## Choose Your Contribution Type
You can either:

- Add a notebook to an existing section (**HDA**, **HOOK**, **STACK**), or
- Add a new standalone section (external cookbook repository).


## Add a Notebook to an Existing Section

1. **Use the official notebook template:**
   https://github.com/destination-earth/DestinE-DataLake-NotebookTemplate/blob/main/notebooks/template.ipynb

2. **Push your notebook to the `staging` branch** of the DEDL Lab repository:
   https://github.com/destination-earth/DestinE-DataLake-Lab/tree/staging

   Include thumbnails or images in the `img/` folder of the same repository.

> Until the workflow is updated, notebooks must still be placed in `staging`.

After the next run of `build_myst_page.yml`, your notebook appears in the gallery.

You can trigger the build manually:
https://github.com/destination-earth/DestinE-DataLake-Gallery/actions/workflows/build_myst_page.yml


## Add a New Section (External Repository)

### Step-by-Step

1. **Use the template repository**
   Clone or click "Use this template":
   https://github.com/destination-earth/DestinE-DataLake-NotebookTemplate

2. **Add your notebooks and images**
   - Place notebooks inside `notebooks/`
   - Ensure first cell contains YAML metadata
   - Place thumbnails in `img/`

3. **Configure your repository**
   - Enable GitHub Pages (Settings → Pages → Source: GitHub Actions)
   - Enable workflow write permissions

4. **Submit your repository**
   Open an issue here:
   https://github.com/destination-earth/DestinE-DataLake-Gallery/issues

   Provide:
   - Repository URL
   - Title
   - Folder name keyword

5. **Review and Integration**
   When the issue is closed, the repository is automatically integrated.

## Best Practices

- Use clear and descriptive titles.
- Maintain consistent tagging conventions.
- Ensure notebooks execute without errors.
- Keep notebooks minimal, informative, and well-documented.
- Provide context for users unfamiliar with your dataset or workflow.
